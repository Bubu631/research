# Public-data integration protocol

The first complete execution uses the fixed `CONFIG` in `experiments/digits_upgrade.py`: seeds 1701-1705, a 64-48-10 ReLU classifier, 12 balanced-training epochs, then 24 continuation epochs on training digits 0-4 only. Optimizer: momentum SGD, learning rate 0.15, momentum 0.9, batch size 128. The continuation begins from the exact incumbent checkpoint. No external checkpoints or proprietary data are used.

Data: scikit-learn's 1,797-example digits dataset, with 8x8 pixel inputs scaled by the known range 16. Stratified partitions are 40% training and 20% each for development, certification, and reporting. Partitions are disjoint within each seed. No reporting or certification observation is used to train, choose coefficients, set tolerances, or change this protocol.

Search: compare 121 scalar coefficients against an 11x11 two-layer grid (121 candidates). The two blocks are the first affine layer and the output affine layer, each including its bias. On development data, every class is protected by a 0.03 absolute accuracy non-inferiority margin. The objective weights each digit 0-4 at 0.16 and each digit 5-9 at 0.04. Feasible candidates are ranked by objective, then worst constraint slack, then less parameter movement. One final policy is selected using development data only. Certification evaluates that single frozen candidate with per-slice Hoeffding lower bounds at level 0.05 using the paired difference range [-1,1]. If it fails any slice, the released model is the exact incumbent. The exact incumbent identity is handled structurally, not inferred from coincident predictions.

The reporting split supplies descriptive class accuracies for the incumbent, updated, scalar, layer, and released models. It does not revise the selection. Report every seed and every certification failure. With about 36 certification observations per digit, conservative bounds are expected to have low power; abstention is a valid outcome. Five repeated stratified splits reuse the underlying dataset, so variability across seeds is descriptive and must not be represented as an independent population confidence interval.

Dataset references: [scikit-learn loader](https://scikit-learn.org/stable/modules/generated/sklearn.datasets.load_digits.html), [UCI Optical Recognition of Handwritten Digits](https://archive.ics.uci.edu/dataset/80/optical+recognition+of+handwritten+digits). This is neither MNIST nor a multilingual or foundation-model evaluation.
