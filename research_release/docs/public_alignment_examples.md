# Public Post-Edit Alignment Diagnostics

The diagnostic records document the alignment between archived machine translations and reference post-edits. The export retains dataset revision, record identifiers, source digests, token IDs, revision masks, and edit counts. Archived and detokenized surface text is retrieved from the original public corpus when reproducing the diagnostic.
