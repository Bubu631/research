# Full-parameter gradient extension: fixed protocol

Frozen on 2026-09-11, after the initial output-bias experiment and before any full-parameter gradient computation. This is an explicitly subsequent scope check, not a preregistration predating the entire project. The initial output-bias results motivated checking a larger parameter block; the sample, selection functions, alignment, checkpoint, and all three reported mechanisms are unchanged.

Use the same 256 reporting records of the English-German public-post-edit protocol, the same archived MT/PE alignment, and the same pinned Helsinki-NLP/opus-mt-en-de snapshot. Preserve the model's default trainable-parameter set: tied parameters count once, sinusoidal position tables remain fixed, and the artificial output-bias adapter is not included. Model evaluation mode remains enabled, with no optimizer or parameter update. The gradient target is the sentence-uniform mean of per-sentence token-mean post-edit NLL, including EOS.

For P uniform and each of the three declared Q distributions (edit, length, edit_length), compute full edited and untouched mean gradients. This gives eight vectors over all default trainable parameters. Use batches of four sentences, no truncation, attention masks on source padding, ignored target padding, and divide each sentence's component sum by its own full target length. Accumulate model-autograd float32 gradients on CPU in float64 memory-mapped banks. Compute the eight-vector Gram matrix blockwise in float64; retain the parameter order, source IDs, model/data hashes, losses, and bank hashes. Large raw banks remain a regenerable local cache, not a GitHub artifact.

For alpha=0,0.05,...,1, report rho_Q, rho_P, absolute bias, both mean norms, the general quadratic coefficients, and all derivative signs. Report all three mechanisms and any disagreement with the bias-adapter findings. These are exact population means up to floating-point computation on a fixed public finite sample; no confidence interval for real production or unseen language pairs is implied.

The extension uses frozen mean gradients and makes no full-parameter fine-tuning, translation-quality, or optimizer-performance claim. Importance-weighting recovery is an algebraic property of the known synthetic sampling design; no new claim of authentic complaint propensity identification is made. Raw text and pretrained weights are not distributed with the paper package.

Numerical checks: edited plus untouched per-example losses must reconstruct full token-mean loss; finite-difference derivative of the Gram-based ratio must agree with the polynomial derivative where the denominator is nonzero; report symmetry and eigenvalue diagnostics of the Gram matrix. Any incomplete execution must be labeled incomplete and excluded from completed evidence.

Implementation correction before any completed full-gradient result: the first attempt stopped at the first autograd call because the serialized model marked sinusoidal position tables as requiring gradients even though their forward method is explicitly under `torch.no_grad()`. The executed library source was checked. The revised implementation explicitly fixes those two position tables, as already intended above, and rejects any other unused gradient rather than silently discarding it. The first attempt's script and manifest are preserved; this is not a change to records, selection mechanisms, or outcome criteria.
