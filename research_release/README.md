## Quick start

Run these commands from the **repository root** after cloning:

```bash
cd research_release
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements-core.txt
python experiments/verify_artifact_integrity.py
make test
```

All subsequent commands on this page run from `research_release/`. The recorded environment used Python 3.13; [requirements-core.txt](requirements-core.txt) pins the core dependencies. Optional pretrained-model tests skip when model dependencies are absent. The integrity check validates saved hashes and explicitly lists the eight intentionally omitted large gradient arrays; it does not rerun experiments.

To regenerate both synthetic studies and the two public digits training paths, then build both PDFs:

```bash
make reproduce-core
make papers
```

PDF compilation requires `latexmk`, `pdflatex`, and BibTeX. Experiment commands write into `papers/*/results/` and `figures/`; use a separate clone or preserve a copy before reproducing the recorded evidence. The full historical Python package list is in [requirements-recorded.txt](requirements-recorded.txt).

## Public translation and gradient studies

Install the additional dependencies, then regenerate both translation directions and their combined report:

```bash
python -m pip install -r requirements-models.txt
make reproduce-public
python experiments/verify_public_geometry.py
```

This downloads public human post-edits and pinned pretrained models. The experiment uses 512 records per direction (English–German and English–Chinese), partitioned into 256 diagnostic and 256 reporting records, and evaluates 180 fixed one-step output-bias adapters in total. The [protocol](docs/public_postedit_protocol.md) and saved manifests record revisions, source licenses, selected IDs, seeds, and settings. The two recorded runs were replayed on the same environment: all 30 numeric files matched byte for byte; this is not a guarantee of cross-platform identity.

`verify_public_geometry.py` requires the per-record `public_gradients_*.npz` files regenerated by `make reproduce-public`. They are excluded from this compact Git checkout. The retained summaries and population means remain available without them. An existing separate `public_gradient_evidence.zip` can also restore the eight arrays when extracted from the repository root, preserving its `research_release/` paths; the archive is not required if regenerating them.

The native-parameter extension computes eight mean gradients across 73,886,208 active parameters on the same 256 English–German reporting records:

```bash
make reproduce-full
```

The recorded run took 36.9 minutes on an Apple M1 Pro with 16 GB unified memory. Its temporary float64 gradient bank requires 4.73 GB, in addition to downloaded assets and other outputs. The script uses MPS when available and otherwise CPU; it also accepts `--device cpu`. Set `PUBLIC_POSTEDIT_CACHE` to choose the cache location. Runtime and floating-point results can vary by hardware.

The retained 8-by-8 Gram matrix permits independent geometry checks without the model or large bank:

```bash
python experiments/verify_native_geometry.py
```

That check writes a derived validation JSON. It does not reconstruct or independently rerun the native gradient bank.

## Evidence boundaries

- **Edit localization:** the public text, human post-edits, and pretrained-model computations are real; the selection mechanisms are declared synthetic interventions. They do not identify actual complaint propensities. Hard localization raises relative bias while reducing absolute bias in all three native endpoint comparisons. One output-bias curve has an interior maximum, so endpoint ordering does not establish general monotonicity. Importance weighting does not uniformly improve held-out one-step NLL.
- **Model upgrades:** the simulations use explicit bounded-score populations. The integration study trains a small NumPy classifier on scikit-learn’s 1,797-example digits dataset. Both the selective and later balanced continuation paths return the incumbent in every fixed seed. The later path improves mean reporting accuracy but still fails certification; it reuses holdouts and is descriptive. These are not foundation-model or multilingual upgrade results.
- **Statistical scope:** mathematical results depend on their stated estimands and assumptions. Monte Carlo repetitions, reused records, and training seeds are different sources of variation and are reported separately. Seed variability alone is not a confidence interval for deployment performance.
