## What each repository contains

- An English README, manuscript PDF, compilable LaTeX, figures, and citations.
- Scientific code, dependency specifications, tests or independent validation routines.
- A `configs/` directory with explicit execution profiles, a command runner, and a Makefile.
- Recorded experimental results, source snapshots, data provenance, and evidence limitations.
- Its own complete repository bundle and manuscript source package under GitHub Releases, with SHA-256 checksums.

The NHS repository includes the complete preceding NHS ranking study under `prior_study/`. The edit-localization repository hosts its additional large numerical-gradient archive in its own release. Raw upstream download caches and pretrained model weights are restored through the documented source references when needed.
