# Frozen empirical gradient diagnostic

Recorded 2026-09-12 before full gradient-bank extraction and before inspecting its audit-MSE outcomes. It is a subsequent study relative to the initial controlled groups and constructed stateful training. The historical group availability amendment and exact serialization are in `swe_gym_data_protocol.md` and `swe_token_protocol.md`.

Use every one of the 49 heldout G8 task groups (392 records), including all-equal labels. Cached historical verdicts define a fixed finite empirical target, not on-policy expected return. Canonicalize the last nonempty assistant message, including tool call arguments, with at most 1,536 preceding-context and 512 target tokens. Do not select records based on outcomes or gradient magnitudes. No test-result text outside the original visible conversation enters model inputs.

The pinned Qwen2.5-Coder-1.5B-Instruct checkpoint is frozen. At output logits add B*eta, with B a fixed Rademacher matrix scaled by sqrt(32), seed 20260915. Differentiate mean target-token log probability at eta=0: mean(B[target] - softmax(frozen_logits)*B). Frozen forward logits use fp16; the added-bias parameterization and analytic score use fp32. This is an actual 32-dimensional model-defined score, not the native full-parameter gradient. The policy is not trained. At this checkpoint the empirical surrogate's ratios are one, so the two sign-split coefficient blocks share the score map / G. Mathematical clipping checks are a separate experiment.

Primary cheap probabilities come from the previously frozen task-train logistic proxy. The heldout targets do not train or calibrate it. Unit query cost counts a cached verdict reveal; actual test execution costs are unavailable and no speedup is inferred. Compare full, proxy completion, whole-group residual, fixed exponent-one prefix, coefficient-model prefix, gradient-model prefix, reward HT then normalization, and partial replacement then normalization at 0.25, 0.50 and 0.75 expected label fractions. The gradient-model schedule uses exact enumeration of 256 possible labels under the working model, with the fixed score map; it accesses no actual label. It optimizes that model's gradient metric for fixed query order, not arbitrary misspecified-label risk. Pre-audit query order is p*(1-p), descending with stable ties.

Integrate prefix audit distributions and all 256 independent masks exactly. Report 49-group mean MSE and ratio to whole-group residual. Use 10,000 paired task bootstrap resamples, seed 20260916, for pointwise percentile ratio intervals. One G8 group corresponds to each heldout task; do not treat 392 trajectories as independent or count the overlapping G4 grouping as replication. Report zero-target groups, actual score extraction time, scheduler overhead, full-audit probability, and all method losses. The experiment is not a benchmark score, a deployment claim, or a statement about the behavior policies' logged likelihoods.
